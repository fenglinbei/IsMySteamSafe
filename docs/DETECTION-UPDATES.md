# 0.2.8 检测范围与规则更新

本轮针对检测能力审查发现的缺口实施更新。它仍是按需运行的本地只读审计，不是通用杀毒软件，也不证明账户或整台电脑安全。

## 检测变化

- Valve 发行者身份必须同时满足 Authenticode 验证成功与精确的证书主体身份，不能由任意主题子串代替。已声明的 Millennium 加载器仍允许合理的核对提示，但损坏或无法验证的签名不会因此放行。
- Steam 前端检查中的读取失败、文件/字节上限以及无法解析的路由目标会保留覆盖不足；仅出现方法名或路由键不是完整验证。
- 自动发现已安装游戏目录、全部本地工坊 AppID、已适配 MOD 和 Steam 插件。各根目录交错遍历，达到数量、时间、大小限制后明确列出未完成来源。普通游戏根目录扩大了范围，但这仍是有上限的轻量扫描。
- 在预算内对可读文件计算 SHA-256，不再先按有限扩展名排除未知文件。C#、JavaScript、Python、Lua、PowerShell 等支持有界静态组合检查。未知格式、编译后二进制、快捷方式、字节码及归档会说明未完成的语义或内部检查。
- 新组合规则结合下载和载荷执行、敏感存储读取和外传、工坊传播或破坏等线索。不会执行脚本、编译 MOD、解包安装器或连接其中的地址。单个网络地址、反射 API、未签名文件或正常 MOD 本身不会判为病毒；组合提示也只是“需要核对”。

内容阶段仍受 5,000 条目、256 MiB 哈希读取、单文件 64 MiB、约 12 秒遍历及深度上限约束。客户端检查和后续关联取证另计。大型游戏库通常不能一次完成，必须查看覆盖说明，而不能以零发现代替安全结论。

## 规则来源与边界

内置规则版本 `2026100201`，发布日期 2026-10-02，48 个精确 SHA-256：原有 39 条本地样本/复核记录，以及新增的 9 条 [G DATA BlockBlasters 原始分析](https://blog.gdatasoftware.com/2025/09/38265-steam-blockblasters-game-downloads-malware) 所公开的指纹。新增记录自带 `sourceUrl`；哈希只能识别字节完全相同的对象，不能覆盖该家族的所有变体。标签中的“已确认”说明来源结论，本次构建不执行这些样本。

[People Playground 开发者 2026 年 9 月事件公告](https://store.steampowered.com/oldnews/?appgroupname=People+Playground&appids=1118200&feed=steam_community_announcements&headlines=0) 说明了 C# 模组风险。加入 C# 覆盖解决了原来的静默跳过，但没有取得并验证该事件全部真实样本，因此不宣称已经检测其所有变体。

[卡巴斯基 2026 年 6 月壁纸研究](https://securelist.com/dozens-of-malicious-wallpapers-found-on-steam-workshop/120186/) 涉及多个家族、加密归档和会话盗取。本版仍不展开归档、不做内存指令分析，也不能可靠追溯已经退出的进程或已经发生的凭据外泄。该报告公开 MD5，不能在没有可信对应证据时直接转换或假冒为 SHA-256；本轮没有据此捏造指纹。

## 用户如何更新规则

1. 在“检测规则”区域查看版本、发布日期、来源及文件指纹数量。
2. 点击“打开规则发布页”，从项目 GitHub Releases 下载 `IsMySteamSafe-rules-*.json`。只有这个用户动作会打开浏览器，程序不自动检查网络更新。
3. 点击“导入官方规则包”。校验通过后保存到 `%LOCALAPPDATA%\IsMySteamSafe\Rules\active.rules.json`，下一次体检使用新快照。既有报告保留当时的规则版本。

规则包是数据，不能引入可执行脚本或更换检测引擎。新增语法、扫描范围及检测逻辑仍需要更新应用程序。初始发行包的规则与内置版本相同，导入它用于离线分发及校验，不会凭空增加检出能力。

程序固定内嵌发行者 RSA 公钥，验证 RSA-PSS/SHA-256 签名，拒绝修改、陌生密钥、重复 JSON 字段、无效/重复指纹、旧版本、不兼容引擎、过期或超过一年有效期的包。更新只能增加规则，不能删除或改写内置及当前有效的外部记录。导入先完整验证，再在跨进程排他锁内核对当前版本并原子替换；失败不覆盖现有包。已保存的包每次加载重新验证，失效时回到内置规则并明确提示。

不向证书信任库写入数据，不从包内接受任意公钥。该机制防止伪造更新和误降级，不抵御同一 Windows 用户替换整个程序、删除本地规则或修改系统时间；它也不授予本工具内核、云查杀或实时防护能力。

## 维护者发行

`scripts/new-rule-package.ps1` 读取已审核的内置 JSON 与版本常量，以指定证书私钥签名。公钥资源是公开证书，不包含私钥。正式本地构建会使用最终 SelfTest 可执行文件验证该签名包的导入、重新加载、幂等及失败保护，结果见 `RULE-PACKAGE-RESULTS.json`。CI 不持有发布私钥，使用临时测试密钥检查签名协议正反例。

规则更新要求递增版本、保留来源证据和合法内容负例，并通过测试后发布；不要把合成回归测试数量当作实际恶意样本检出率。更新包有效期目前为发布日期后 180 天。公钥轮换需要新应用版本。
