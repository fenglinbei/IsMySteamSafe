# 0.2.7 统一启动与错误报告

本轮发行标签为 `v0.2.7-preview.1`，产品版本为 `0.2.7`。面向 Windows x64，最低 Windows 10 build 19041，固定 .NET SDK 10.0.400、自包含 .NET 10.0.12。用户仍启动原来的 `IsMySteamSafe.exe`，无需选择两个下载版本。

## 何时使用兼容模式

原生入口静态链接 MSVC 运行库，不加载 CoreCLR。它核验完整负载清单后，调用 `IsMySteamSafe.Standard.exe` 的早期探针。探针只确认托管入口已就绪，在创建 WPF、发现 Steam 或执行审计前退出。

只有探针尚未就绪、输出包含已知 CET 初始化错误，且退出码为 `0x80131506`，才调用 `IsMySteamSafe.Compat.exe` 再探测一次。Standard 保留 CET 标志，Compat 关闭本程序宿主的 CET 标志，二者共享相同 DLL。强制 CET 的系统策略仍可能阻止启动。每次启动重新探测，不持久缓存模式选择，不修改注册表中的防护配置。

未知退出、超时、输出过量、错误的就绪随机值、清单不匹配或兼容探针失败都会停止启动。探针使用随机握手和受控输出管道，超时结束其 Job 中的进程。真正的业务进程只启动一次；运行时失败不会自动重放扫描或导出。

## 权限和安装

App 与原生入口保持 `asInvoker`，安装器保持当前用户安装及原 AppId、默认目录和快捷方式。不存在 Broker、归档 Worker、提权、系统防火墙写入或自动信任证书操作。新包仍只进行审计，不能删除、隔离或修复目标文件。

启动器检查 `SHA256SUMS.txt` 全部条目，保留文件锁、拒绝路径跳转和未知 DLL/EXE 等可加载文件；Inno 的根目录 `unins000.exe` 是安装器例外。文件系统访问支持传统 MAX_PATH 之外的包内元数据路径。完整性校验不能证明包来源可信，也不能阻止同一用户同时替换启动器和清单，来源应结合签名、源码身份和发行哈希核对。

先退出旧程序，再运行完整安装器升级。不要仅替换主 EXE，也不要把便携包覆盖到混有其他程序 DLL 的目录。`IsMySteamSafe.exe --startup-check` 可只做启动预检并输出模式及诊断报告位置，不打开窗口、不执行体检。

0.2.6 留下的 `mscordaccore_amd64_amd64_10.0.1126.37416.dll` 不属于新版运行时。安装器只在该精确名称及公开旧包 SHA-256 均匹配时清理它；其他文件或被修改的同名文件保持原样，后者仍会导致完整性检查拒绝启动。便携包请解压到新目录。

## 本地报告

- 启动报告：`%LOCALAPPDATA%\IsMySteamSafe\Logs\startup-*.txt`；备用 `%TEMP%\IsMySteamSafe-Startup-Reports`。
- 托管错误：同一 Logs 目录下的 `error-*.log`；备用 `%TEMP%\IsMySteamSafe-Error-Reports`。
- 日志记录软件与构建身份、系统与运行时信息、启动模式、错误码或可取得的异常链和堆栈。大小与保留数量有界，避免日志无限增长；记录失败不会递归报错。
- 常见凭据和用户目录会脱敏；不主动附带扫描内容、账户文件、完整环境变量或内存转储，不自动上传。用户取消不会作为未知故障报告。

反馈时发送错误提示指向的报告，并说明发生时间和操作。分享前仍需查看其中是否存在不愿共享的本机路径。原生入口本身无法运行、强制终止、磁盘不可写等情况可能没有日志，仍需 Windows 事件日志或外部诊断脚本。

## 构建与验收

发布脚本从干净 Git 树导出源快照，在固定 SDK/运行时上构建和执行原生自包含 SelfTest，生成三个宿主并核验实际 PE CET 位。自有 3 个 EXE 和 2 个 DLL 在生成清单前签名，安装器及卸载器签名随后完成。源码 ZIP、便携 ZIP、机器可读结果、发布身份与 SHA-256 随发行提供；GitHub CI 独立验证同一提交。

结果以 `RELEASE-METADATA.json`、`SELFTEST-RESULTS.json`、`UNIFIED-STARTUP-RESULTS.json` 及发布验收摘要为准。SelfTest 的计数是测试组，不与其他工具的断言数量混为一谈。与本机 Steam 有关的条件检查应根据结果中的覆盖字段判断，未安装 Steam 不等于完成真实客户端验证。

统一启动测试包含真实自包含宿主探针和合成故障。合成 CET 错误只能证明选择逻辑，**受影响旧 Win10 CET 硬件尚未复测**，不能声称所有无法启动问题已解决。最终包在独立干净 Win10/Win11 与其他用户账户的安装、升级、卸载仍需验证；历史 UI、扫描和安装记录保留原版本身份。当前是无公共受信任证书链、无时间戳的自签名预发布。
